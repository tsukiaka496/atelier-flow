# 背景画像（プリセット）

このフォルダに、次の **3 ファイル** を置いてください。

| ファイル名 | 内容 |
|-----------|------|
| `marble.jpg` | 大理石 |
| `aurora.jpg` | オーロラ |
| `night-sky.jpg` | 夜空 |

## 推奨

- 形式: JPG（`.jpg`）推奨。PNG / WebP も可（その場合は `lib/themeBackgrounds.ts` の拡張子を合わせて変更）
- サイズ: 横 1600px 前後、ファイル 500KB 以下程度（表示は `cover` で全体に敷きます）
- アスペクト比: 4:3 〜 16:9 あたり

設定画面の「背景画像」から選べるようになります。
